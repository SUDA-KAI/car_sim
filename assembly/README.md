# 支架与传感器三维装配台

打开本机页面 **http://127.0.0.1:8767**。服务未运行时：

```bash
cd /home/a/ros2_ws/gz_sim
./run_assembly_editor.sh
```

编辑器与 ROS / Gazebo 分开运行，不会给小车发运动指令，也不会自动改写 `sensor_mounting_tf.yaml` 或当前仿真模型。三维资源在本地，不依赖在线 CDN。

## 使用方法

1. 在左侧选择主控总支架、L2 支架、左右相机支架或四路超声波支架/本体。初始摆在车旁的是待装配位置，不是推算出来的安装位置。
2. 先选择“固定到哪个部件”，例如第三根横杠或主控支架。更换父部件会保持当前空间位置，之后移动父部件会带动子部件。
3. 拖动彩色轴移动，切到旋转工具调整姿态；也可在右侧填写相对父部件的位置（毫米）和 RPY（度）。位置吸附为 1 mm，旋转吸附为 5°；撤销/重做保留操作记录。
4. 用 Shift + 单击模型表面，或打开“标记表面点”后单击，添加带编号的表面点。给点写上孔位/安装面的说明。选择 A、B 后，“点重合”只移动 A 所在部件；“安装面贴合”会让两点重合、表面法向相对，但仍需检查绕法向的转角与其余孔位。
5. 安装说明可写“主控支架底面贴第三横杠上表面，长边朝前，点 1 对准点 2”等。位置检查完成后可勾选“已确认”；改动部件位姿会清除它和子部件的确认状态。
6. 点击“保存到本机”，下次打开自动载入。也可以下载 JSON 发给协作者；本机的安装说明与点号足以继续装配。

旧配置首次载入会自动追加右相机支架及四路超声波外形，并在 `backups/before_extra_meshes_r*.json` 留存原记录；既有部件位姿、说明、标记和版本号不变。旧浏览器草稿也会补齐新部件后恢复。

## 保存与导出

- 主记录：`assembly_settings.json`，包含父子关系、位姿、说明、确认状态和表面标记。原子保存，每次保存前备份到 `backups/`。
- 浏览器另有未保存草稿，快速刷新/关闭前也会保留。多页保存遇到版本冲突会拒绝覆盖，可先下载当前草稿，再刷新合并。
- “导出装配草稿”写到 `exports/`：`patrol_car_assembly.urdf`、`assembly_frames.yaml`、`assembly_snapshot.json`。未确认部件仍按当前摆放导出，属于草稿。URDF 保留原车惯量/碰撞，暂不增加支架质量或碰撞，不自动安装进运行中的 Gazebo。装配关系确定后，再把视觉模型与传感器位姿统一接入运行场景。

服务默认只监听本机 8767 端口。HTTP 接口：`GET /api/state`、`POST /api/state`（携带 revision）、`POST /api/export`（先保存同一 revision）。如果是远端电脑访问，可用 SSH 转发本机端口；无需改为公网监听。

## 部件参考点在哪里

页面默认开启“参考点 / 包围框”：选中部件后，**黄色 O** 是该部件当前编辑参考点（未自定义时为原局部 (0,0,0)），**蓝色 P** 是父部件局部 (0,0,0)。黄色线框显示所选部件自身网格的包围盒，不包含其子部件；虚线连接 P 与 O。标示只用于编辑，既不参与表面点选，也不改变保存的数据或导出模型。

| 部件 | 默认参考点 O |
|---|---|
| 车身 base_link | 车身地面中心 |
| third_crossbar | 第三根横杠几何中心，车身坐标 (90,0,495) mm |
| L2 | 底部安装面中心，沿用点云坐标原点 |
| 主控/L2/左右相机/左右超声波支架、四个超声波本体 | 模型未旋转时，STL 包围盒底面矩形的中心 |
| 左右相机与外置 IMU 的示意外形 | 示意盒几何中心，使用填写的设备安装坐标 |
| ultrasonic_N 测距坐标 | 原测量表中的测距参考点，与支架、本体编辑原点分开 |

包围盒底面中心不一定在实体表面或螺孔上；有孔洞的支架可能在空处。这个点在模型局部坐标中固定，旋转后跟随部件，不会重新选世界最低点。右侧显示该点在原 STL 中的毫米坐标，方便与 CAD 对照。

输入的 XYZ 是部件 O 在父部件 P 坐标系中的位置，RPY 让部件围绕 O 旋转。改变父部件时会重新换算 XYZ/RPY，以保持当前空间位置。选择“聚焦所选”可看清参考点和包围框；标记表面点是另一个功能，不会改变 O。

实际浏览器检查确认各类部件说明、O 的显示位置和装配数据保持不变。证据：`../artifacts/assembly_origin_guides_validation.json`、`../artifacts/assembly_origin_guides_canvas.png`。

## 用百分比指定 O

选中有实体的部件，勾选“自定义 O 的相对位置（百分比）”，设置 X/Y/Z 各 0～100%。也可直接点快捷按钮：

- `(50%,50%,0%)`：本部件包围盒的底面中心。
- `(50%,50%,50%)`：包围盒几何中心。
- `(0%,0%,0%)`：包围盒最小 X/Y/Z 的角点。
- `(100%,100%,100%)`：对面的最大角点。

按部件自己的轴和包围盒计算，旋转后仍跟随部件。百分比改变时只重新选择编辑参考点，实体、子部件、标记和安装确认状态不动。XYZ 输入会显示当前 O 相对父部件 P 的位置，拖动/数值旋转会围绕当前 O；如果父部件也选择了自定义 O，子部件的位置输入相应以该 P 为参照。需要原先的点时，点“恢复原参考点”。

每个部件单独保存 `pivot_percent`，旧配置不设该字段时保持原先行为。原传感器坐标和 URDF 物理部件坐标不因选择 O 而重定义；编辑 O 的几何位置与百分比通过装配快照保存。真正移动/旋转部件时，会换算到底层部件位姿，使页面与 URDF 几何一致。没有实体的第三横杠/测距参考坐标不提供包围盒百分比，保留原测量定义。

7 项后端测试和独立配置上的浏览器检查通过。覆盖旋转过的部件选择百分比参考点时实体/子部件/标记不动、XYZ 平移与绕 O 旋转、拖动控制器绕 O 旋转、父参考点换算、保存重载及物理导出坐标一致性。证据：`../artifacts/assembly_percent_pivot_validation.json`。

### “模型底面”和“当前朝向底部”

“模型底面（未旋转）”固定指局部 `(50%,50%,0%)`。如果原参考点本来就是这个点，选择后 O 不会移动，页面会提示两点重合。它不是地面 Z=0，也不保证在旋转后仍朝下。

新增“当前朝向底部”快捷按钮，按整车 Z 向上判断包围盒当前最低的面、边或角。对于主控支架绕 X=90° 的当前姿态，朝下底面中心为 `(50%,0%,50%)`；在部件坐标约 `(0,0,495)` mm 的情况下，O 从 `(0,0,495)` mm 变到 `(0,-95,290)` mm，实体不动。一般斜放时最低处可能是一条边或一个角，按钮会显示对应名称及百分比。

实际浏览器验证了上述 90° 情形及三个一般姿态的最低高度，保持部件矩阵不变；用户草稿没有被自动改成测试参数。证据：`../artifacts/facing_bottom_pivot_validation.json`。
